# Purpose
Guide agents to build an enterprise-grade Swift Vapor back-end for open-erp — “Enterprise software without the robbery.”

## Code Quality
Write the simplest, most readable code. Balance configurability with streamlined design. Limit code and test bloat.

## Documentation
Read current Vapor documentation because prior knowledge is outdated. Use https://docs.vapor.codes/ and https://api.vapor.codes/.

## Compliance
Design for SOX compliance and SOC controls.

## Testing
Ensure code is well tested. Never write tests for the sake of testing.

## Proposals
Root every fix, bug solution, or feature proposal in the Framework or API docs, or demonstrate it via a demo.
